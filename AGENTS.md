# Pull request repository guardrail

- Pull requests against the upstream repository are prohibited:
  https://github.com/senjinthedragon/SillyTavern-Discord-Connector
- Pull requests may target only the fork:
  https://github.com/kuo77122/SillyTavern-Discord-Connector
- Before creating a pull request, verify that its base repository is
  `kuo77122/SillyTavern-Discord-Connector` and its base branch is `main`.
- Push only to `origin`. Never push to `upstream`, and never open or retarget a
  pull request against the upstream repository.
